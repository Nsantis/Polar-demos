# Polar demos
 
#How to Use

##Setup:

Save the HTML file to your computer
Open it in a Chrome browser (WebBluetooth is best supported in Chrome)
Make sure your Polar H10 is powered on and nearby


##Connect:

Click "Connect to Polar H10"
Select your device from the Bluetooth dialog
Wait for the connection to be established


##Monitor:

Watch as the charts populate with your physiological data
The breathing rate is calculated after you've gathered about 15 seconds of data
For best results, try to remain relatively still during monitoring


##After Use:

Click "Disconnect" to properly close the connection
Click "Reset Data" if you want to clear all charts and start fresh
